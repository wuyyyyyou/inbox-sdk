# Anna Inbox 2.1.6 架构与发布基线

## 产品基线

2.0 的主界面是三栏工作台：左侧 AI 侧栏，中间 Inbox Workspace，右侧账户栏。点击邮件后，Mail Detail 从工作区右侧展开。

前端当前直接渲染 `HomeView`；Brief / Ask 后端工具继续服务 AI 侧栏。设置含 **AI Personalization**（Saved prompts / Memory）与连通性检测。

对外称「AI 助理」：自然语言搜索 / 总结 / 写改稿 / 批量草稿 / 整理建议；**无**日历自动约、**无**静默 mutation、整理须用户确认。

## 当前进度（App 2.0.25 / Tool 2.1.6）

- **AI turn 阶段 C（本版本）**：
  - 白名单新增 `batch_draft` / `batch_outreach`：按 `ui_context.selected_threads` 逐封隔离证据写稿（上限 5）。
  - 收件箱列表多选 → `selected_threads`；侧栏一条消息内多 `artifacts` 展示。
  - 删除前端业务意图路由 `decideAiRoute` 与 `anna-inbox-use-ai-turn` 旁路；侧栏**仅** `start_ai_turn`。
  - `aiRoute.ts` 仅保留 `buildRevisionPrompt`（邮件上下文 prompt 包装）。
- **阶段 A+B（既有）**：Router / search / summarize / draft / revise / propose / remember / Saved prompts / Memory。

### 未完成 / 明确不做

- Host Agent Session 不作为默认 LLM 路径。
- 日历 / MCP / Tasklet / 静默 mutation 不在本对话 Router 范围。
- `translate_thread` / `extract_*` 等分析类 tool 可后续增量接入。

## 代码边界

- `mail_agent/ai_turn/router.py`、`runner.py`、`tools.py`：白名单 Router 与批量写稿。
- `anna_inbox_executa/ai_turn_flow.py`：可轮询 `start_ai_turn` + multi-artifact 结果。
- `app/useAppController.ts`：统一 `startAiTurn` + `selected_threads` + multi-artifact 解析。
- `features/home/HomeView.tsx`：收件箱多选、批量草稿 UI、空态文案。
- `app/aiRoute.ts`：仅 revision prompt 辅助（非意图路由）。
