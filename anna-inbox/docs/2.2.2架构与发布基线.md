# Anna Inbox 2.2.2 架构与发布基线

## 产品基线

2.0 的主界面是三栏工作台：左侧 AI 侧栏，中间 Inbox Workspace，右侧账户栏。点击邮件后，Mail Detail 从工作区右侧展开。

对外称「AI 助理」：自然语言搜索、总结、写改稿、批量草稿和整理建议；整理、发送、删除和标签 mutation 均须明确用户操作确认。

## 当前版本（App 2.1.2 / Tool 2.2.2）

### 富文本撰写与外发

- 回复 / 转发 / Compose 使用 `RichTextEditor`（contenteditable + 工具栏）：加粗、斜体、下划线、预设字号、固定色板、列表、链接、撤销重做。
- 草稿与发送契约新增可选 `body_html`；`body` 仍为纯文本兼容字段。
- 后端 `outgoing_html.sanitize_outgoing_html` 白名单净化后写入 MIME multipart/alternative；禁止脚本、事件属性与任意样式。
- 转发说明区仅编辑用户附言 HTML；原信引用块不进入可编辑区。

### AI 侧栏 Router 与澄清

- Router 提示词集中到 `ai_turn/prompts.py`；输入约 500 tokens、输出 150 tokens 预算裁剪。
- 无歧义高频意图走 `fast_local_route`，跳过一次 Sampling。
- Router 无法判定时返回结构化 `clarification`；前端弹层支持 `inbox` / `current_thread` / `compose` / `chat` 范围选择与自由输入。
- 用户选定后通过 `ui_context.routing_intent` 直达白名单计划，避免二次澄清。
- 详情页邮件协助与改稿统一 `start_ai_turn` + `requested_artifact`，不再由关键词猜 artifact。

### Ask / 线程回答与 Sampling

- Ask 默认返回 3 条、显式数量上限 8；按请求解析条数并限制上下文候选。
- 截断 JSON 抛 `TruncatedJsonResponse`，不再补括号伪装成功；模型不可用返回 `analysis_unavailable` 等稳定错误码。
- 线程总结优先最近 4 封、每封 600 字符证据；失败不回退主题/snippet 伪摘要。
- Sampling 按 Host grant 收敛（默认总 token 32k、单 call 8k、最多 8 次）；run 结果暴露脱敏 `sampling` 用量摘要。
- `start_ai_turn` 首 invoke 短 wait（≤5s）只建 run，完整结果由轮询；Gmail 401/403 空结果恢复为授权失效提示。

### 继承能力

- 外发多附件 stage、Cc/Bcc、发送前 10 秒可撤销。
- 多邮箱切换：取消上一扫描 + 本地缓存首屏 + History 静默同步；Gmail 401 force_refresh。
- 收件附件元数据/列表回形针、平台安全 trace 诊断。
- AI 侧栏 Ask 仅检索当前活动邮箱。

## 代码边界

- `features/mail-detail/RichTextEditor.tsx`：富文本编辑与前端净化。
- `mail_agent/mail_providers/gmail/outgoing_html.py`：外发 HTML 白名单。
- `mail_agent/mail_providers/gmail/adapter.py`：回复/撰写 HTML MIME。
- `mail_agent/ai_turn/router.py`、`runner.py`、`prompts.py`：路由预算、澄清、线程回答。
- `anna_inbox_executa/ai_turn_flow.py`、`sampling_tools.py`：短 wait 建 run、预算快照、授权失败语义。
- `mail_agent/ask/answer.py`、`sampling_budget.py`、`llm_runtime/service.py`：条数、预算、JSON 解析。
- `app/useAppController.ts`、`features/home/HomeView.tsx`、`features/home/ComposeView.tsx`、`features/mail-detail/MailDetailDrawer.tsx`。
