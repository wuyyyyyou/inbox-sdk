# 平台超时诊断与反馈流程

## 适用范围

用于 Anna 平台中 AI 对话、收件箱读取或连通性检测出现超时，而本地 `anna-app dev` 不易复现的情况。

本地与平台的调用拓扑不同：平台会经过 iframe 工具调用、Executa、Reverse RPC、凭据代理与外部服务；本地通常复用本机凭据和本地开发宿主。因此必须以同一次平台调用的分段耗时判断边界，不能仅凭最终 timeout 推断。

## 安全诊断字段

含对象 `data` 的工具响应与工具错误可携带 `diagnostics`，后台 AI run 则通过 `get_mail_agent_run` 返回同一 trace。字段只包括：

- `trace_id`：随机诊断编号。
- `operation`、总耗时及阶段耗时。
- `credentials.list_accounts`、`credentials.get_token`、`gmail.token`、`gmail.http`、`sampling.create_message` 和 `executa.invoke`。
- HTTP 状态码、稳定 endpoint 类别、token 来源枚举和错误类型。

诊断不会记录邮件正文、主题、邮箱地址、Gmail message/thread ID、查询参数、token、credential context、Sampling prompt 或模型输出。

## 复现步骤

1. 在平台刷新到包含该 Tool 版本的 App，确保 Google Connected accounts 和 Sampling 权限均已启用。
2. 先在 AI 侧栏发送一次不读邮箱的短对话，再发送一次邮箱搜索或线程总结；记录失败消息中的 `Diagnostic rt_...` 及其阶段行。
3. 在收件箱执行一次首次加载、下一页加载和打开线程；失败时从工具错误中的同类诊断行记录 trace。
4. 对同一账户、相同操作在本地 `anna-app dev` 重复一次，保存两侧 trace 的阶段耗时。不得复制邮件内容或凭据。
5. 若最小 Sampling 或 `users/me/profile` 调用在平台连续失败三次，且耗时稳定停留在 Reverse RPC 阶段或外部服务之前，整理为平台问题报告。

## 判定规则

| 诊断现象 | 初步归属 | 后续动作 |
| --- | --- | --- |
| `sampling.create_message` 超时，且短提示词连续复现 | Anna Sampling / 宿主链路 | 提交平台报告 |
| `credentials.list_accounts` 或 `credentials.get_token` 超时 | Connected accounts / 凭据代理 | 提交平台报告 |
| `gmail.http` 超时，但凭据阶段快速成功 | Google API 或平台出口网络 | 先复测，再提交平台报告 |
| 前端 `tools.invoke` 超时且没有任何 Tool trace | iframe runtime / 工具进程启动 | 提交平台报告 |
| 本地与平台都在同一 Gmail 或模型阶段超时 | 上游服务或请求负载 | 缩小请求并保留上游证据 |

## 报告模板

```md
标题：平台 Executa 调用在 [Sampling / Connected accounts / Gmail HTTP] 阶段间歇超时

App 版本：2.0.28
Tool 版本：2.1.9
环境：staging / 平台运行
时间区间：YYYY-MM-DD HH:mm 至 HH:mm（时区）
权限状态：Sampling 已授权；Google Connected accounts 已授权

复现步骤：
1. ...
2. ...
3. ...

预期：最小调用在工具 timeout 内返回。
实际：连续 N/M 次超时。

安全诊断：
Diagnostic rt_xxxxxxxxxxxx (NNNNms)
credentials.get_token NNNms
gmail.http NNNms TimeoutError

本地对照：相同操作成功，关键阶段耗时 ...ms。

未附带邮件正文、邮箱地址、message/thread ID、token、prompt 或 credential context。
```

论坛帖子应附上平台 trace 链接或 trace id（如平台支持），并说明是否已按 [Anna LLM sampling is unstable](https://forum.anna.partners/t/anna-llm-sampling-is-unstable/83) 检查 Sampling 授权与最新发布版本。
