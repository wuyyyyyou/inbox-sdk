# 本地持久化统一改造

## 问题

当前本地持久化路径散落在项目目录各处（`.local_storage/`、`.data/gmail_cache/`、`scripts/.../gmail_tokens/`），平台运行时这些路径不存在或不可写。

## 目标

平台运行时，所有持久化数据统一写入 executa 工作目录下的 `.data/`。

## 平台检测

```python
def _is_platform() -> bool:
    if getattr(sys, "_MEIPASS", ""):
        return True
    if os.environ.get("GMAIL_ACCESS_TOKEN") or os.environ.get("GOOGLE_ACCESS_TOKEN"):
        return True
    return False
```

## 统一入口

```python
def data_root() -> Path:
    if _is_platform():
        return Path("./.data/").resolve()
    else:
        return (Path(__file__).resolve().parents[1] / ".data").resolve()
```

## 路径映射

| 旧路径 | 新路径（平台） |
|--------|--------------|
| `inbox-tool/src/.local_storage/` | `.data/` |
| `inbox-tool/src/.local_storage/runs/background/` | `.data/runs/background/` |
| `inbox-tool/src/.data/gmail_cache/` | `.data/gmail_cache/` |
| `scripts/google_token/.secrets/gmail_tokens/` | 平台不需要 |

## 最终目录结构

```
.data/
├── cards/{mailbox}/active.json

```
