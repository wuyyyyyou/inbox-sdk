# 附件下载与外部链接

## 当前实现

邮件详情从 Gmail 元数据读取附件列表。前端通过 `prepare_inbox_attachment_access` 请求轻量访问描述，不通过 JSON-RPC 返回附件字节。

附件访问路径按运行环境选择：

1. Cloud Agent / APS 模式：APS files/object storage 引用。
2. 本地开发模式：local loopback URL。

前端支持图片、PDF 和受限文本附件预览；其他格式提供下载或外部打开。PDF 使用 `pdfjs-dist` 渲染。HTML 正文使用 DOMPurify 清洗后展示。

## 安全约束

- 后端校验 mailbox、message ID、attachment ID 和 mode。
- 不把附件、长 HTML 或 base64 blob 写入 APS KV。
- 文件名、MIME 和 URL 都视为不可信输入。
- `blob:` URL 使用完必须释放。
- 外部链接使用受限协议并避免获得 opener 控制权。
- 附件读取不应改变 Gmail 已读或标签状态。
