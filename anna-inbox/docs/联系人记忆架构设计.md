# 联系人记忆架构

联系人记忆为当前 Gmail thread 之外的长期上下文，主要服务 Brief 判断、线程总结和草稿生成。

## 隔离与存储

- 按 mailbox 和 contact email 隔离。
- 存储 key：`mailbox/<mailbox>/contacts/<contact>/memory`。
- 每个 contact 文件包含受限数量的 thread summaries 和 message summaries。
- 邮箱 registry 不保存联系人正文或 credential。

## 写入

`contact_memory/indexer.py` 从卡片和线程上下文生成候选，`manager.py` 负责运行编排，`store.py` 通过统一 storage 层 upsert。LLM 只生成摘要，代码负责去重、截断和版本兼容。

## 召回

`retriever.py` 只在同 mailbox、同 contact 下选择相关历史，并排除当前 thread。不确定时返回空，避免把无关联系人信息注入 prompt。

## 隐私

- 不跨邮箱共享记忆。
- 不存 OAuth token 或完整 credential context。
- 删除单个或全部联系人记忆必须使用显式工具调用。
