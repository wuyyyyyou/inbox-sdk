# 邮件详情抽屉

## 当前结构

`MailDetailDrawer.tsx` 是 2.0 Inbox Workspace 的详情体验，不是旧 Attention Card Handle 页面。

打开邮件后，前端按需加载线程页和显示正文，并可继续分页。正文优先展示清洗后的 HTML，失败时回退文本。AI overview、正文和附件各自维护加载与错误状态。

## 草稿

- 本地草稿按 mailbox + thread ID 持久化。
- 保存使用 `etag` / `if_match` 避免并发覆盖。
- AI 可以基于当前 thread 生成或修改草稿。
- 用户仍可直接编辑草稿。
- 发送成功或明确丢弃后删除本地草稿。
- `dry_run=false` 的发送只能来自用户点击 Send。

## 邮件操作

抽屉支持 Todo、Done、Snooze、已读、星标、重要和 Trash。UI mutation 失败时必须回滚本地乐观状态或重新同步 Gmail。

## 边界

- 大正文和附件不写 KV。
- 引用旧消息时需要清理历史 quoted content，避免重复注入 LLM。
- 切换邮箱或邮件时，异步结果必须校验当前 mailbox/message/thread，防止串数据。
