# Anna Inbox 2.2.7 架构与发布基线

## 产品基线

2.0 的主界面是三栏工作台：左侧 AI 侧栏，中间 Inbox Workspace，右侧账户栏。点击邮件后，Mail Detail 从工作区右侧展开。

**唯一智能入口**为 Anna AI Sidebar：默认 Host Agent Session；本地可用 `source=sidebar_local` 兼容路径。Brief 产品面下线。整理、发送、删除和标签 mutation 均须明确用户操作确认。

## 当前版本（App 2.1.7 / Tool 2.2.7）

### 邮箱同步：缓存优先（P0）

- 列表 `display_range_days`（7/30/60）**仅**控制 Inbox 展示投影，不限制 AI 检索范围。
- 首次连接 / 清缓存后优先同步最近 **180 天** All-mail **metadata**；更早历史后台无硬顶 backfill，page token 可断点续跑。
- `sync_inbox_cache` 用 History 增量合并；可选 Gmail Watch 注册；前端 `auto_sync_seconds`（默认 15s）轮询兜底。
- 每个邮箱暴露 `sync_boundary`（最早/最晚索引时间、priority/backfill 完成态、history 游标等）；禁止把索引诊断原文当作用户答案。
- 实现：`mailbox_sync.py`、`gmail_tools.py`、`adapter.py`；前端 `silentSyncInbox`。

### AI 只读取证：`query_mail_evidence`

- Host / local 侧栏主路径约定：邮箱范围问答**只调一次** `query_mail_evidence`（Scope → QueryPlan → 确定性缓存 Evidence）。
- Host agent 白名单以 `query_mail_evidence` 为只读检索入口（不再直接暴露 `search_email` / `read_email` / `ai_summarize_thread` 给 Host）。
- `search_email` / `read_email` 仍保留为 Agent 内部或兼容实现：**只扫本地缓存**，不实时打 Gmail；`order=oldest|newest`；`read_email` 的 `bodyFull` 仅返回已缓存正文，未同步时 `body_pending`。
- 用户明确时间目标**早于** `earliest_indexed_at` 时，Evidence 可做一次受限 Gmail 历史检索（最多 20 条并回写缓存）；失败须说明无法判定，禁止答「没有」。
- `display_range_days` 不得写入 Agent 选型上下文作为检索边界。
- 实现：`evidence_flow.py`、`ai_agent_tools_flow.py`、`aiAgentSystemPrompt.ts`、`local_agent_session.py`。

### 正文 / 附件预处理（后台受限）

- 缓存消息可生成 `content_analysis`（清洗正文、引用、签名联系人、发票字段、附件解析状态）。
- 附件：文本/Office ZIP 文本 / PDF（`pypdf`，≤30 页）；图片标记平台 OCR pending；单附件 8MiB、数量上限 12。
- 起草回复可刷新完整 thread 证据；普通搜索仍 cache-only。
- 实现：`content_preprocess.py`、`preprocess_cached_content_batch`。

### 侧栏 local 调试路径

- `ANNA_INBOX_AI_SIDEBAR_MODE` / `localStorage anna-inbox-ai-sidebar-mode`：`host`（默认）或 `local`。
- local：`start_ai_turn(source=sidebar_local)` → Sampling 多步选型 + **同一套** `handle_ai_agent_tool`；无 UI 提示、无真流式。
- 实现：`aiSidebarMode.ts`、`local_agent_session.py`、`useAppController.ts`。

### 草稿产物与详情体验

- 侧栏草稿卡片支持 Reply / Forward / Compose 可编辑后插入编辑栏。
- 详情打开后滚到线程底部；同线程同步刷新保留附件预览；抽屉在列表短暂丢消息时不强制关闭。
- `ai_draft_reply` 支持 `thread_ref` / `message_id` / `thread_id`（抽屉关闭时也可起草）。

### 继承能力

- 邮箱级 workflow state / AI Ask history（乐观并发 etag）。
- 收件附件 Host transient upload → APS Files；reverse-RPC 超时约 20s。
- 联系人头像仅 People API；缓存刷新后预热。
- 平台安全 trace；失败日志不含邮箱、查询、邮件或凭据。

3. 相关 Python 测试：`test_ai_agent_tools`、`test_gmail_history_sync`、`test_inbox_feed`、`test_local_query` 等
4. `describe` / `health` newline-delimited JSON smoke test
5. 仓库无 token、缓存、bundle、本地 storage 或根目录 `tests/` 跟踪表
