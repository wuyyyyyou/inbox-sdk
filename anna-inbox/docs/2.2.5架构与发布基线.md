# Anna Inbox 2.2.5 架构与发布基线

## 产品基线

2.0 的主界面是三栏工作台：左侧 AI 侧栏，中间 Inbox Workspace，右侧账户栏。点击邮件后，Mail Detail 从工作区右侧展开。

**唯一智能入口**为 Anna AI Sidebar（`start_ai_turn` / Host Agent Session）：自然语言搜索、总结、写改稿、整理建议。Brief 产品面下线。整理、发送、删除和标签 mutation 均须明确用户操作确认。

## 当前版本（App 2.1.5 / Tool 2.2.5）

### search_email 实时 Gmail 与列表工作流上下文

- `search_email` 使用标准 Gmail 查询实时检索，不再只扫本地缓存，也不回退缓存。
- 本地工作流条件 `is:todo` / `is:done` / `is:snoozed` 仅支持 AND；从查询中拆出后在结果上过滤。
- 前端侧栏提交 `inboxListContext`（`mailbox_view`、`inbox_group`、`search_input`、`active_search`、`todo/done/snoozed_message_ids`、可选 `custom_category`），作为只读事实写入 `ui_context`。
- 单次搜索硬上限 20 条轻量字段（date / participants / subject / bodySnippet + THREAD_REF）；去掉按 conversation 的 6 次 / 45 候选会话预算。
- Gmail 失败时向用户说明错误，不伪装成空缓存。

### 附件下载与 APS reverse-RPC

- 收件附件：优先 Host transient upload，Host 协商不可用时回退 APS Files；本地 dev 保留 loopback。
- 前端 `storageProvider=local` 时 KV 可走 local-json，但平台附件仍可能调用 APS Files；Executa 始终路由 `files/*` / `storage/*` reverse-RPC 响应。
- Host / APS reverse-RPC 超时约 20s，低于前端 tools.invoke 60s，便于返回可读错误。

### 邮件详情与正文展示

- 打开线程后固定滚到详情底部；HTML iframe 渲染完成与布局变化时继续锁定底部。
- 网络页到达后不再被较慢的缓存 hydration 覆盖。
- 引用清理支持 `>>` 前缀；inline/CID 资源不计入下载附件列表；线程缓存需附件元数据完整才跳过 Gmail 刷新。
- `SafeEmailHtml` 二次过滤危险节点并提供 `onRendered`。

### 联系人头像与 AI 消息

- 邮件缓存刷新后预热当前快照联系人头像；仅 Google People / 账户头像，移除 Gravatar 回退。
- AI 消息：行内标题补行、元数据未闭合 `**` 容错、多行 `[DONE]` 清理；线程摘要人类可读字段合计不超过约 30 词。

### 继承能力

- Host Agent Session 流式会话、白名单工具、取消/恢复；详情/兼容路径保留本地 Router 与 `start_ai_turn`。
- 回复/转发/Compose 富文本、外发多附件 stage、Cc/Bcc、发送前可撤销。
- Sampling grant 预算快照；多邮箱切换与 History 静默同步；平台安全 trace 诊断。

## 代码边界

- `anna_inbox_executa/ai_agent_tools_flow.py`、`mail_agent/local_query.py`：Agent 搜索与本地工作流过滤。
- `anna_inbox_executa/v2_tools.py`、`common.py`：附件上传路径与 APS reverse-RPC 路由。
- `features/home/HomeView.tsx`、`app/useAppController.ts`：列表上下文与头像预热。
- `features/mail-detail/MailDetailDrawer.tsx`、`shared/SafeEmailHtml.tsx`：详情滚动与 HTML 展示。
- `mail_agent/mail_providers/gmail/adapter.py`：Gmail 搜索、附件提取、联系人头像。

## 发布门槛

1. `python scripts/sync/sync_executa_identity.py --check`
2. `cd anna-inbox && npm test && npm run build`
3. 相关 Python 脚本式测试（ai_agent_tools / local_query / attachment / gmail body / contact avatars）
4. `describe` / `health` newline-delimited JSON smoke test
5. 检查仓库中没有 token、缓存、bundle 或本地 storage
